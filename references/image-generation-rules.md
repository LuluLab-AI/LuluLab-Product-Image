# 图片生成规则

- 每张图都传入所有有效产品原图。用户提供达人图时，所有含人物的生成一并传入这些达人图，并在 Prompt 中明确区分产品身份与人物身份；用户未提供达人图时直接生成最终视觉，不得先生成 AI 达人参考图。
- 图片模型只生成视觉底图。Prompt 明确“禁止广告文字、字幕、水印”，并按 `top-title`、`left-title` 或 `bottom-card` 预留干净区域。
- 同一套中各卡功能、景别或画面组织应推进信息，不能只是同一摆拍换背景。
- 最多同时生成 3 张。任务处于排队/处理中时只轮询该任务，不再次提交。
- 生图结果含明显乱码或主要广告文字时，该 Card 视为失败，允许重新生成一次纯视觉图。
- 视觉 Gate 检查产品身份、人物一致性、交互、遮挡、构图留白和可读区域。失败只修复该卡。
